# Weekly Task Overview

Objetivo: darle a Nacho una vista clara y accionable de todo lo que tiene abierto en Patrocinio y NFL, porque su mayor problema es la falta de orden.

## Pasos

1. Leer `context/current-priorities.md` para prioridades y deadlines vigentes.
2. Leer el `README.md` de cada carpeta en `projects/` para conocer estado actual de cada proyecto.
3. Agrupar el output en dos bloques: **Patrocinio** y **NFL**.
4. Para cada proyecto incluir: nombre, estado (activo / planificación / en pausa), y próximo deadline o hito si existe.
5. Poner primero, en una sección **Urgente**, cualquier proyecto con deadline en las próximas 2 semanas desde la fecha de hoy.
6. Cerrar con una sección **Sugerencia de foco esta semana**: 1-2 proyectos a priorizar según deadlines y estado.

## Formato

Seguir `.claude/rules/communication-style.md`:
- Bullet points, no párrafos largos.
- Sin guiones largos (—).
- Tono profesional pero cercano.

## Al terminar

Preguntar a Nacho si algún proyecto cambió de estado o deadline, y si es así, actualizar `context/current-priorities.md` y el `README.md` del proyecto correspondiente.
